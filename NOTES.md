Free tier. In zsh write `${M}:generateContent`, `$M:g…` is a modifier and yields an empty 404.

- Bumble card anatomy: `#bumble.grid_profile.name_label` ("Name, 22"), `#bumble.grid_profile.about.text`, `#profilecard.lifestyle_height`, scroll container `#bumble.grid_profile.content.scroll` (sometimes missing right after a swipe → scroll NO_MATCH, harmless). - Gemini `generateContent` returns 503 sometimes; retry with backoff. `gemini-3.1-flash-lite` ~1.5-8s per card with 1-3 screenshots.
- 2026-09-17 Tinder web DOM (verified live on desktop Dia): `.recsCardboard__cards` holds ~3 stacked cards at the same rect; ONLY the top one is `aria-hidden="false"`, the rest are preloaded next cards. Name/age = `[itemprop="name"]` / `[itemprop="age"]` (no h1). One photo loaded per card until `button[aria-label="Next Photo"]` inside the card is clicked. Like/Nope = gamepad buttons whose span text is LIKE/NOPE (no aria-label). Judging the first visible photo element = judging a background card while swiping the top one (the 1.0.7 "identical verdicts" bug).
- Decision order (both lanes): not-a-woman → grainy → rejected body → face below min → dyed hair → NO FULL-BODY PHOTO → then likes: face ≥ likeFace, swimwear, curves, like-bodies → unsure/ratio. User rules: every like needs a full-body photo, cute/sexy face yes, ugly faces no, dyed hair no, politics keywords no.
- 2026-09-17 DESKTOP LANE = Dia tab + `tools/dia_bridge.py` (launchd com.sly.swiper-bridge, log /tmp/swiper-bridge.log). The page can't fetch card photos itself: CloudFront serves the signed .webp URLs WITHOUT Access-Control-Allow-Origin (curl shows none), and a page->http://127.0.0.1 proxy hangs in Chrome 153 behind the Local Network Access prompt (Browser.grantPermissions localNetworkAccess did not unblock it). So provider `bridge`: page queues {id, text, urls} in window.__swiperBridge, the helper polls over CDP, fetches photos in Python, judges (Gemini 3.5-lite → 3.1-lite → OpenRouter free), delivers via __swiperBridge.deliver. It also re-injects + restarts the lane every 30s if the tab reloaded. `tools/dia_inject.py --local --start` = manual restart.
- Gemini free tier is PER MODEL per day: 3.1-flash-lite died after ~600 requests (11:07), 3.5-flash-lite had a fresh bucket. Vision failure must HOLD (onFail=wait), never pass blind: with onFail=nope the lane passed ~1400 cards blind in one morning.
- 2026-09-17 ALL PHOTOS: the desktop Tinder card renders only "Profile Photo 1"; Next Photo clicks (JS or trusted CDP) never add more images, and a trusted click at the Next Photo rect SWIPED the card. So swiper.js hooks window.fetch + XHR for `/v2/recs` responses and keeps `window.__swiperRecs[name|age] = {photos (processedFiles 480-800w), text (bio + interests + descriptors)}`. Cards injected before the hook (first batch after a reload) fall back to photo 1. Judgments went from 1 photo to 5-9.
